# 📊 Predicting Exam Scores Based on Study Hours

A beginner-friendly machine learning project that uses **simple linear regression** to predict student exam scores based on hours studied.

└── README.md # This file


---

## 🧠 Problem Statement

> Can we predict a student's exam score based on how many hours they study?

This project demonstrates a complete ML workflow:
- Data generation
- Model training using `LinearRegression`
- Performance evaluation with `MAPE` and `R²`
- Visualizing results with Matplotlib
- Interpreting slope/intercept for explainability

---

## 📊 Model Results

- **MAPE**: ~12% → Good prediction accuracy  
- **R² Score**: ~0.94 → Strong fit  
- **Equation**:  

---
score = 5 × hours - 1 (approx)
